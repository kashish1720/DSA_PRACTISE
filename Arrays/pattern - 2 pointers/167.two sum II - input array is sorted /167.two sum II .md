## Problem ko simple Hindi mein padh

Ek array hai, **chhote se bade order mein sorted**: `[1, 3, 4, 6, 9]`
Target = **10**

Kaam: aise **do numbers** dhoondo jinka jod (sum) 10 ho.

Yahan answer: `1 + 9 = 10` ✅

## Socho tum khud kaise karoge?

Tum sabse pehle **pehle number** ko lete ho (1), aur baaki sab ke saath jodte ho: 1+3, 1+4, 1+6, 1+9. Phir 3 ko lete ho... Ye bahut time leta hai. Isse **brute force** kehte hain.

Two pointer mein hum **smart** tareeke se karte hain.

## Two Pointer: ek chhota sa khel

Array: `[1, 3, 4, 6, 9]`, target = 10

Do ungli rakho:
- **i** = sabse **pehle** number pe (left, sabse chhota)
- **j** = sabse **last** number pe (right, sabse bada)

```
 1   3   4   6   9
 i               j
```

**Step 1:** `1 + 9 = 10`. Target mil gaya! Khatam. 🎉

Ye toh easy tha. Ab thoda mushkil example lete hain, target = **13**:

```
 1   3   4   6   9
 i               j
```

**Step 1:** `1 + 9 = 10`. Ye 13 se **chhota** hai. Sum badhana hai. Kaise? Left wale ko **aage** badhao (bada number lo): **i++**

```
 1   3   4   6   9
     i           j
```

**Step 2:** `3 + 9 = 12`. Abhi bhi chhota hai. **i++**

```
 1   3   4   6   9
         i       j
```

**Step 3:** `4 + 9 = 13`. ✅ Mil gaya!

## Sirf ek rule yaad rakh

| Sum kaisa hai? | Kya karna hai? | Kyun? |
|---|---|---|
| Target se **chhota** | **i++** | Sum badhana hai, toh bada number chahiye |
| Target se **bada** | **j--** | Sum ghatana hai, toh chhota number chahiye |
| Target ke **barabar** | Answer mil gaya | Bas |

Bas itna hi. Poora two pointer isi rule pe chalta hai.

## Ye kaam kyun karta hai?

Maan le sum **bada** hai, jaise `1 + 9 = 10` aur target 5 hai. 9 ke saath koi bhi number jodoge toh sum kam se kam 10 hi aayega (1 sabse chhota tha). Toh **9 kisi bhi haal mein answer ka part nahi ho sakta**. Isliye usko hata do (j--).

Array sorted hai, isliye ye guarantee milti hai. Isliye sorted array dekhte hi two pointer yaad aana chahiye.

## Code (ab ye samajh aayega)

```java
int i = 0;                  // left ungli
int j = numbers.length - 1; // right ungli

while (i < j) {
    int sum = numbers[i] + numbers[j];

    if (sum == target) {
        return new int[]{i + 1, j + 1};
    }
    else if (sum > target) {
        j--;   // sum bada hai, right wala hatao
    }
    else {
        i++;   // sum chhota hai, left wala badhao
    }
}
```

Har line wahi hai jo humne upar haath se kiya tha. Code kuch alag nahi hai, bas us khel ko likh diya hai.

(`+1` isliye ki LeetCode index 1 se maangta hai, array mein index 0 se shuru hota hai. Bas.)

Poora code:

java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        int i = 0;
        int j = numbers.length - 1;
        while (i < j) {
            int sum = numbers[i] + numbers[j];

            if (sum == target) {
                return new int[]{i + 1, j + 1};
            }
            else if (sum > target) {
                j--;
            }
            else {
                i++;
            }
        }
        return new int[]{-1, -1};   // "kuch nahi mila" wala safety return
    }
}
Yaad rakhne wali baat

Jis function ka return type int[] (ya koi bhi non-void) hai, uske har possible raaste ka end return pe hona chahiye. Tere notes mein bhi ye likha tha ({-1, -1}), bas code likhte waqt chhoot gaya. Ye bahut common galti hai, sabse hoti hai.
