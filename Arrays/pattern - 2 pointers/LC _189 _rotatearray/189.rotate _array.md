# Rotate Array — Poori Detail Mein Samjho (Hinglish)

## Question Kya Hai

```
Given an integer array nums, rotate the array to the right by k steps,
where k is non-negative.
```

**Example:**
```
Input: nums = [1,2,3,4,5,6,7], k = 3
Output: [5,6,7,1,2,3,4]
```

**Constraints:**
```
1 <= nums.length <= 10^5
-2^31 <= nums[i] <= 2^31 - 1
0 <= k <= 10^5
```

## Step 3: Computer Ye Kaise Sochta Hai (Pattern Dhoondo)

Computer "last 3 utha ke aage rakho" jaisa insaan ki tarah nahi soch sakta. Usse **har number ka exact naya address (index)** batana padega.

Dekho har number kaha se kaha gaya:

```
Number 1 (purani jagah 0) → nayi jagah 3
Number 2 (purani jagah 1) → nayi jagah 4
Number 3 (purani jagah 2) → nayi jagah 5
Number 4 (purani jagah 3) → nayi jagah 6
Number 5 (purani jagah 4) → nayi jagah 0
Number 6 (purani jagah 5) → nayi jagah 1
Number 7 (purani jagah 6) → nayi jagah 2
```

Pattern: **har number apni purani jagah se `k` (yaha 3) aage chala gaya.**

```
nayi jagah = purani jagah + k
```

---

## Step 4: Problem — Number Array Ke Bahar Chala Jaaye Toh?

Number `5` index `4` pe tha. Formula lagao: `4 + 3 = 7`

Par array mein index `7` hai hi nahi (sirf `0` se `6` tak hain, kyunki 7 numbers hain).

**Solution:** `% n` (modulo) lagao, jaha `n` = array ka size.

```
Number 5 ka naya index = 7 % 7 = 0   ✓ sahi bhi yehi hai
```

### Poora Formula

```
nayi jagah = (purani jagah + k) % n
```

---

## Step 5: `%` (Modulo) Kya Hota Hai — Bilkul Basics Se

`%` tumhe **division ka baaki bacha hua (remainder)** batata hai.

```
7 % 3 = 1     (7 ÷ 3 = 2 baar poora hota hai, 1 bacha)
10 % 5 = 0    (10 ÷ 5 = 2 baar poora, 0 bacha)
4 % 5 = 4     (4, 5 se chhota hai, poora ka poora bach jaata hai)
```

**Sabse important observation:** `x % n` ka answer **hamesha `0` se `n-1` ke beech** hi aata hai, kabhi `n` ya usse bada nahi.

### Ghadi (Clock) Wali Analogy

Socho ek ghadi jisme sirf 5 numbers hain: `0,1,2,3,4` — phir wapas `0` pe.

```
        0
    4       1

    3       2
```

```
0 % 5 = 0
4 % 5 = 4
5 % 5 = 0   ← ek pura chakkar lagaya, wapas 0 pe aa gaye!
6 % 5 = 1   ← ek chakkar + 1 aage
```

**Array ke indices bhi isi tarah "ghadi" hain** — jab index array size se bahar chala jaaye, `% n` use karke usse wapas "circle ke andar" le aate hain.

## Step 6: Chhota Example — 3-3 Steps Mein Bilkul Slow Samjho

```
nums = [10, 20, 30], k = 1
```

**Number 10 (index 0):**
```
nayi jagah = (0 + 1) % 3 = 1
```
10 ab index 1 pe jayega.

**Number 20 (index 1):**
```

```
20 ab index 2 pe jayega.

**Number 30 (index 2) — YAHA RUKO:**
```
nayi jagah = (2 + 1) % 3 = 3 % 3 = 0
```
Index `3` exist nahi karta (sirf 0,1,2 hain), isliye `%` ne use wapas `0` bana diya.

**Final Result:**
```
index 0 → 30
index 1 → 10
index 2 → 20

Result = [30, 10, 20]
```

Check karo — manually bhi yehi answer aana chahiye (1 step right rotate): `[30,10,20]` ✓

## Step 7: `int[] result = new int[n]` Kyun Chahiye

### Real Life Example

Socho tumhare paas **7 khaali dabbe** hain, line mein rakhe:

```
[ _ ][ _ ][ _ ][ _ ][ _ ][ _ ][ _ ]
  0    1    2    3    4    5    6
```

`int[] result = new int[n];` bas itna hi karta hai — **`n` khaali dabbe bana deta hai**, jinme baad mein numbers daalenge.

### Iski Zarurat Kyun Padi

Agar tum seedhe original `nums` array mein hi likhna shuru karo (bina naye array ke), toh purane numbers **overwrite ho jayenge unhe padhne se pehle hi**:

```
nums = [1,2,3,4,5,6,7]

nums[3] = nums[0]  →  nums = [1,2,3,1,5,6,7]
```

Dekho — `4` (jo index 3 pe tha) **hamesha ke liye kho gaya**, use kahi save nahi kiya tha. Ab jab `4` ko uski nayi jagah bhejna hoga, wo mil hi nahi payega.

**Isliye ek alag, khaali array (`result`) banate hain**, jisme hum numbers ko unki nayi jagah pe daalte hain — bina original `nums` ko turant chhede. Jab sab kuch `result` mein sahi jagah pe aa jaata hai, tab wapas `nums` mein copy kar dete hain.

---

## Step 8: Poora Java Code

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;        // total kitne numbers hain
        k = k % n;                  // agar k, n se bada hai toh chhota bana lo
        int[] result = new int[n];  // nayi khaali jagah, jaha naya answer rakhenge

        for (int i = 0; i < n; i++) {
            int newPosition = (i + k) % n;   // har number ki nayi jagah nikaalo
            result[newPosition] = nums[i];   // usko wahan rakh do
        }

        for (int i = 0; i < n; i++) {
            nums[i] = result[i];    // result ko wapas nums mein copy kar do
        }
    }
}
```

### Line-by-Line Explanation

| Line | Matlab |
|---|---|
| `int n = nums.length;` | Pata karo total kitne numbers hain |
| `k = k % n;` | Agar `k` array size se bada hai (jaise k=10, n=7), toh usse chhota bana do — kyunki `n` rotations ke baad array wapas apni original jagah aa jaata hai |
| `int[] result = new int[n];` | `n` khaali dabbe bana lo, jisme naya answer store hoga |
| `for (int i = 0; i < n; i++)` | Har purane number ko ek-ek karke dekho |
| `int newPosition = (i + k) % n;` | Formula lagao — ye number ab kaha jayega |
| `result[newPosition] = nums[i];` | Us number ko uski nayi jagah pe rakh do |
| Dusra `for` loop | `result` se wapas `nums` mein copy karo (kyunki method `void` hai, in-place answer chahiye) |

## Sabse Zaroori Baatein (Summary — Yaad Rakhne Ke Liye)

1. **Core Formula:**
   ```
   nayi jagah = (purani jagah + k) % n
   ```

2. **`%` (modulo) ka kaam:** Jab index/number array ke size se bahar chala jaaye, use wapas "circle ke andar" le aata hai — jaise ghadi mein 12 ke baad wapas 1 baj jaata hai.

3. **`k = k % n` shuru mein hi kyu karte hain:** Agar `k` array size se bada ho (jaise k=10, n=7), toh `n` rotations ke baad array apni original jagah pe wapas aa jaata hai. Isliye pehle hi `k` ko chhota bana lena better hai.

4. **Naya `result` array kyun banate hain:** Taaki original array ke numbers ko unki nayi jagah bhejte waqt **overwrite hone se bachaya ja sake** — bina naye array ke, kuch numbers padhne se pehle hi mit jaate.

5. **General Recipe (Agli Baar Khud Solve Karne Ke Liye):**
   - Chhota example lo, haath se manually karo
   - Har element ke liye poocho — "kaha se aaya, kaha ja raha hai?" (pattern dhoondo)
   - Boundary check karo — "kya index/value array ke bahar ja sakta hai?" → agar haan, `% n` use karo
   - Formula ko code mein convert karo
   - Chhote example pe dry run karke check karo
